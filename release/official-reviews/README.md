# Official review dispositions

This directory holds accepted or rejected review records for exact frozen
candidate evidence. It contains no protocol results, raw exports, screenshots
or default approvals. Follow [the official release gate process](../../docs/official-release-gate.md).

Records are named `<run-id>-<origin-attempt>.json` and take effect only after
normal protected-main integration. Keep the original official REVIEW outcome;
review disposition does not grant certification or video publication approval.
